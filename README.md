# Netflix Clone 🎬

A simple Netflix homepage clone built using **HTML** and **CSS**.  
This project replicates the look and feel of Netflix’s landing page with responsive design.

---

## 🚀 Features
- Responsive layout
- Modern UI design
- Netflix-style navigation bar
- Sections for movies and shows
- Footer with links

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Flexbox, Grid, Media Queries)
